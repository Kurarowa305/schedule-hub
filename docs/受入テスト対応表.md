## 3. 自動化境界

自然言語の解釈、曖昧時の質問、意味によるDestination選択はClaudeの責務である。Schedule Hub側では、その判断に必要な最小Context、推論種別を含む入力Schema、存在・有効性の再検証を自動テストする。Claude公式チャット、Google実アカウント、端末アプリをまたぐ確認はSH-051で実施する。

## 4. 外部表示ガイドの根拠

外部表示画面の手順はTimeTreeおよびYahoo! JAPANの公式ヘルプを参照し、画面名が変わる可能性も表示する。Schedule Hubは外部アプリでの表示成功を保証せず、TimeTree/Yahooへ直接API通信しない。
